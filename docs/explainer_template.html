What the first Bungalow run tells us

From the HTML summary, CSV and audit files of the first Bungalow run on 29 October 2026 (EnergyPlus 26.2.0, Dublin IWEC weather).

10,574 kWhspace heating per year
123 kWh/m²heating over 85.9 m² floor area
3,703 kWhhot water heating per year
6.4 kWsized heating capacity, all rooms
487 hheating setpoint not met (0 h while occupied)
  • The run is usable. 49 warnings and 0 severe errors. Everything in the list above is either expected from a DesignBuilder export or worth one check.
  • The CSV is missing the heating results. ReadVarsESO stopped at 255 columns (see the .rvaudit file), so the ideal loads heating columns never reached Bungalow Original.csv. They are in the .eso file. Trim the output list or read the .eso/.sql instead.
  • Heating shows up as “District Heating Water”. Ideal loads systems and unconnected hot-water use are metered as district heating. Those figures are the heat delivered, which is what a heat pump would have to supply. They are not electricity.
  • The 487 unmet hours all fall outside occupied periods. The ideal loads are capped at their sized capacity (calculated load × 1.25), so rooms warm up slowly after a setback. This matters for a buffer-tank study, because pre-heating is exactly what a tank enables.
  • Sizing gives a heat pump starting point. The calculated room design loads add up to about 5.1 kW, or 6.4 kW with the 1.25 sizing factor (Zone Sensible Heating table in the HTML report).
  • Electricity is only lights and appliances (999 kWh and 1,319 kWh). There is no heat pump in the model, so heat pump electricity has to be worked out from the heat demand in Python.

Checking hundreds of runs

The same rules are in the eptools Python package (no AI, no dependencies). It explains each run, flags failed or suspect runs, reads heating and unmet hours from the HTML report, warns when the CSV was truncated, and can compare each run with a baseline.

python -m eptools check runs/example/run_0001 --baseline runs/example/run_0002 --html report.html
python -m eptools check runs/example/run_* --quiet     # hide the IGNORE items

python -m eptools run study.json runs a whole parameter matrix and does this check on every run automatically. New messages show up as “Not in the rule list yet”. Add a rule to RULES in eptools/check.py and rebuild this page with python docs/build_explainer.py.
